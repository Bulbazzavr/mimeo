# Z-52 и часть C веба: замер до плана — 22 сентября

Карточка части C (`PLAN-8.1`) обещала: «данные уже на странице, работа в CSS и
разметке». Ниже то, что показал счёт. План — `PLAN-8.3`.

Вход везде `examples/content-mimeo.md`. Числа сняты **до** правки, движок на
коммите `b11c81e`. Разовые скрипты замера лежат вне репозитория: итоговые числа
после правки снимает `tools/report.py verify` (`z52-result`), и в документы
идут только они.

## 3. Разложение остатка по видам: донора ноль, всё — наша ширина

После петли итоговая колода меряется ещё раз, осмотр `find_defects` с итоговым

|---|---:|---:|---:|---:|---:|
| `2411-Performance_Up` | 0 | 6 | 0 | 0 | 6 |
| `ArtisticEffectSample` | 0 | 1 | 0 | 0 | 1 |
| `business-plan-…-creative` | 1 | 1 | 0 | 1 | 1 |
| `business_plan` | 0 | 3 | 0 | 0 | 3 |

| `svetlaja-tema` | 0 | 1 | 0 | 0 | 1 |
| остальные четыре | 0 | 0 | 0 | 0 | 0 |
| **корпус** | **1** | **26** | **0** | **1** | **27** |
| VK Tech ×3 | 7, 7, 8 | 0 | 0 | 5, 4, 4 | 0 |
| WorkSpace ×3 | 0 | **0, 0, 1** | 0 | 1, 2, 0 | **0** |
| VK Education ×3 | 0 | 0 | 0 | 0 | 0 |

Три вывода:

- **все 27 «донорских» по корпусу — наши надписи шире своего места.** Строка
  CLI «мы в них ничего не подставляли, чинить нечем» неверна целиком;
- **остаток по раундам не видит итоговую колоду:** у WorkSpace, вариант 3, по
  раундам 0, а в итоге одна ширина — она появилась после последней
  пересборки, а контрольный замер в раунды не пишется. У `biznes-plana`
  наоборот, 2 по раундам и 1 в итоге;
- причина в коде: `RoundRecord.ours = len(inspection.repairable)`, а
  `repairable` есть только у `overflow_height`. `overflow_width` — наш слот с
  `repairable=False`, и он уезжает в тот же остаток.

## 5. Растр нашёл то, чего не видит никто: текст на тексте

WorkSpace, вариант 3, слайд 6 — **сдаточная колода**. Заголовок «Проверку
вёрстки, это наша сильная часть» переносится на вторую строку и **ложится на
текст под ним**. Отчёт: 18 → 0, «всё влезло».

Зонд на этом слайде:

| Фигура | Бокс, пт (x, y, w, h) | Текст, пт | Кегль | К боксу | К месту |
|---|---|---|---:|---:|---:|
| 709 заголовок | 34, 33, 616, 92 | 482 × 78 | 36 | 0.85 | 0.31 |
| 712 текст под ним | 34, 98, 286, 51 | 262 × 43 | 12 | 0.85 | 0.85 |
| 710 | 497, 98, 373, 151 | 369 × 140 | 36 | 0.99 | 0.79 |
| 711 | 497, 283, 373, 204 | 374 × 183 | 48 | 0.94 | 0.74 |

**Боксы 709 и 712 перекрываются в самом шаблоне: 709 кончается на 125, 712
начинается на 98.** Заголовок влезает в свой бокс с запасом, детектору нечего
сказать: он проверяет «влез ли в своё место» и «нет ли непрозрачного сверху»,
а наложения текста на текст не проверяет вовсе. Задача `Z-53`.
