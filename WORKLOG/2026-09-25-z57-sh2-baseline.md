## Командная строка (`mimeo/cli.py`)

- Подкоманды `analyze`, `plan`, `build`; флагов модели нет ни у одной. Справка
  `plan` и `build` говорит «без обращения к модели» — **сегодня правда**: сборка
  модель не зовёт, в Ш3 станет ложью.
- **Конфиг прогона (`--config`) принимает любой ключ, у которого есть флаг**:
  известные ключи — `vars(args)`, приоритет «командная строка выше файла» держит
  `_named_explicitly`. Новые флаги станут ключами конфига сами. **Но значения из
  файла `argparse` не проверяет** — `choices` на них не действуют, значит
  проверка значения нужна своя.
- Сводку печатают два места: `cmd_build` (одна колода) и `_build_variants`
  (`--variants N`); `cmd_plan` — своя сводка. `-q` глушит всё.
- Машинный итог `--report` — контракт с вебом (`contracts/build-report.schema.json`,
  «форма не меняется»): строка о модели в нём — дело Ш10.
- Веб флагов модели не передаёт (поиск `llm` по `web/` — пусто).

## Клиент (`mimeo/plan/client.py`)

- `post_chat` шлёт один заголовок, `Content-Type`; ключа API нет нигде.
- **Ключ кэша** (`ModelClient.key`) собирается из модели, режима, промпта,
  схемы, `params` и `extra_body` — заголовков в нём нет. Ключ API в заголовке в
  кэш не попадёт по построению; в `extra_body` его класть нельзя — утёк бы в ключ.
- **Тело ответа сервера при ошибке HTTP уходит в сообщение** (до 300 знаков) —
  сервер, повторивший ключ в тексте отказа, вынес бы его в диагностику.
- Доступ `off | cache | on` уже есть (`Access`), берётся из `config/model.json`
  (`"access": "cache"`); переопределить его на прогон сегодня нечем.

## Замок колод (`tools/deck_lock.py`)

- Команда: `build <шаблон> <текст> *флаги_задания *хвост_после_-- --output … -q`.
- В замок пишутся хэши шаблона, текста и колод, код возврата и **флаги задания**
  (`NINE` или ничего); хвост не хранится и не сравнивается. Значит `--llm off`
  можно подставить в команду, не трогая `tools/deck_lock.json`.
- `argparse` при повторе флага берёт **последнее** значение: `--llm off` перед
  хвостом даёт `-- --llm cache` его перекрыть. Проверить тестом, а не верой.
