# WORKLOG — лабораторный журнал

Сырые промежуточные результаты: замеры, таблицы, выводы прогонов, находки из
поиска. То, что дорого получить и легко потерять.

## Чем отличается от `docs/`

| Где | Что там | Живёт |
|---|---|---|
| `WORKLOG/` | **числа и факты**: замеры, выводы команд, что показал прогон | вечно, не переписывается |
| `docs/domain/` | обобщённое знание о формате, выведенное из этих фактов | обновляется |
| `docs/architecture/adr/` | решения, принятые на основании фактов | не переписывается, помечается `superseded` |
| `docs/plans/` | планы, логические проверки, чек-листы | статус меняется |
| `docs/journal/` | что делали в этот день, связным текстом | по дням |

Правило простое: **если число получено дорого — оно идёт сюда**, даже если
кажется, что запомнится. Вывод из числа идёт в `docs/`, само число остаётся тут.

Файлы именуются `ГГГГ-ММ-ДД-тема.md`.

## Как перегенерировать

Таблицы в файлах с замерами порождены прогонами, а не написаны руками. Скрипты
порождения описаны в соответствующих планах (`docs/plans/`). Если код изменился,
таблицу надо перегенерировать, а не править вручную.

**Числа `Z-38`, `Z-47` и `Z-48` до 21 сентября перегенерировать было нечем** —
их снимали разовыми скриптами, которые нигде не сохранились. Теперь есть две
стадии:

```
python tools/report.py slots                       сужённые и пустые слоты, без PowerPoint
python tools/report.py verify                      переполнения, заслонения, время
python tools/report.py verify --templates tz/templates --variants 3 --slides 10-15
```

Обе считают **по одному каталогу за раз**: смешивать наш корпус-прокси с
выданными материалами нельзя, у них разный статус. Числа по четырнадцати
шаблонам — сумма двух прогонов.
