# 2026-09-12 · Измеритель вёрстки (`PLAN-4.0`, шаг 1)

Первая часть стадии VERIFY: спросить у PowerPoint габариты текста каждой фигуры.
Модуль `mimeo/verify/metrics.py` плюс зонд `powerpoint_probe.ps1`.

## Сверка с эталоном

## Три дефекта, найденных проверками, а не отладкой

### 1. Второй замер подряд не работал

Критично: петля VERIFY мерит **каждый раунд**.

```
прогон 1: ok            фигур=13
прогон 2: not_measured  фигур= 0   note=BUSY
прогон 3: not_measured  фигур= 0   note=BUSY
```

PowerPoint не завершался после `Quit()`. Причина — обёртки COM: пока переменные
`$sh`, `$tf2`, `$tr` и коллекции `Slides`, `Shapes`, `GroupItems`, `Presentations`
живы в области видимости, сборщик их не трогает, и приложение держится. Явное
`ReleaseComObject` на каждую помогло, но не до конца: процесс всё равно жил
дольше тридцати секунд.

Решение честное, а не косметическое: **свой экземпляр мы вправе завершить.** Зонд
отказывается работать, если PowerPoint уже открыт у пользователя, — значит любой
появившийся после запуска процесс наш. Ждём две секунды, затем `Stop-Process`.

```
прогон 1..5: ok  фигур=13  5.8 с  идентично
```

### 2. Моя собственная проверка детерминированности была пустой

Сравнивались два прогона — «совпало». Но оба вернули **пустой** список, потому
что второй упёрся в `BUSY`. Сравнение двух пустот совпадает всегда.

Поймано только потому, что рядом печатался порядок фигур и он оказался `[]`.
Вывод для себя: проверка на равенство обязана сначала убедиться, что сравнивать
есть что.

### 3. Модуль `measure.py` затенялся функцией `measure`

После реэкспорта в `__init__` имя `mimeo.verify.measure` означало то функцию, то
модуль. Нашлось на `monkeypatch`, который не смог найти атрибут. Модуль
переименован в `metrics.py`; в плане стояло `measure.py`, отклонение сознательное.

## Что проверено

| Проверка | Результат |
|---|---|
| совпадение с черновым зондом | до последнего знака |
| пять замеров подряд | все `ok`, результат идентичен |
| нелатинское имя файла с пробелом | `ok`, 13 фигур |
| битый файл (обрезанный ZIP) | `open_failed` с сообщением, **не пустой ответ** |
| не презентация вовсе | `open_failed` |
| корпус из 11 колод | 11 из 11, 0 отказов, 0 пропущенных фигур |
| тесты без PowerPoint | 14 штук, зелёные |

Самое важное здесь — строка про битый файл. Молчаливый ноль неотличим от «дефектов
нет», и именно так три структурные проверки полгода пропускали нечитаемые файлы
(`WORKLOG/2026-09-12-mce-prefixes.md`). Измеритель обязан отличать «замерил и
чисто» от «не смог замерить».
