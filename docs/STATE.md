## Как запустить

**Все команды выполняются из каталога `mimeo/`** — в нём лежит весь проект.
Стартовый каталог сессии на уровень выше, поэтому первым делом `cd mimeo`.

Всё сразу — **`start.bat`**: при первом запуске ставит в `runtime/` сервер
модели, веса и генератор (и встраиваемый Python, если его нет), поднимает оба
сервера и открывает веб на `http://127.0.0.1:8000`. По отдельности —
`python tools/runtime.py install`, `start`, `stop`.

```
python -m mimeo build путь/к/шаблону.pptx путь/к/контенту.md --output out/deck.pptx
python -m mimeo build путь/к/шаблону.pptx путь/к/контенту.md --llm off --output out/deck.pptx
python -m mimeo analyze путь/к/шаблону.pptx -o out --validate
python -m mimeo plan путь/к/шаблону.pptx путь/к/контенту.md -o out --validate
python -m pytest
```

Первая строка зовёт модель (нужны серверы из `runtime/`), вторая — путь без
неё. Объём — `--slides 12` или `--slides 10-15`; без флага число слайдов решает
модель, а путь без модели — контент (`Z-70`). Полный список команд и
инструментов — `CLAUDE.md`, «Запуск».

**Шаблоны в `samples/` не коммитятся** (они чужие): восстановить —
`python tools/fetch_samples.py samples`. Выданные шаблоны — `tz/templates/`,
тоже вне git.

## Окружение

**Модели и их серверы — в `runtime/`**, вне git; ставит `start.bat` по
манифесту `config/runtime.json`, со сверкой `sha256` (`Z-76`): `llama-server`
с Gemma 4 12B QAT и проектором `mmproj` — текст и зрение, `sd-server` с
Z-Image-Turbo — картинки. Видеокарта — 12 ГБ: Gemma занимает 9, и
`llama-server` отдаёт память генератору после трёх секунд простоя. Что за
модели и почему — `MODELS.md`, лицензии — `THIRD-PARTY.md`, выбор —
`CTX-MODELS`.

**Microsoft Office установлен** (`POWERPNT.EXE`); VERIFY зовёт PowerPoint
через COM из PowerShell, `pywin32` не нужен (`ADR-0013`). LibreOffice не
установлен (`Z-03`, `OQ-16`).

**Продукт — на стандартной библиотеке** (`ADR-0001`, `ADR-0011`). Для тестов
установлены `pytest`, `jsonschema`, `python-pptx`, `lxml`, `Pillow`, `numpy`,
`scikit-learn`; `python-pptx` читает наши файлы как независимый читатель.
