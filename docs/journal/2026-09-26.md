## Новый чат: Ш9 — замер после, растр трёх наборов

Пользователь: «коротко доложи, где мы, и делай Ш9». Замер до плана
(`WORKLOG/2026-09-26-z57-sh9-baseline.md`) сразу сузил задачу: запрос продукта с
промптом 1.2 — **те же ключи**, что у ответов AB3 в Ш6, 10 из 10, а путь без
модели даёт таблицу `CLAUDE.md` до единицы. План, две проверки и обратный план —
в рабочем листе; первая проверка переставила сверку инструмента: сличать
`report.py` не с растром Ш6 (он мог сниматься на коде раньше итогового), а с
растром этого же чата.

**Код.** `tools/report.py verify` мерит колоды модели: `--llm` (умолчание off —
путь без модели, чтобы команды из документов не сменили смысл после Ш8),
`--text`, `--llm-cache`; путь модели — вызовом `cli.model_path`, который теперь
принимает конфиг; модель просили, а колоду она не дала — код 3 до PowerPoint;
цель объёма доходит до плана, как у сборки; картинки считаются по байтам в
файле. Тестов 16 (`tests/test_report_tool.py`).

**Проверка инструмента.** С `--llm off` — числа «до» по 23 колодам из 23; с
моделью — числа команды эксперта по 18 колодам из 18.

**Модель.** Сервер поднят и остановлен. Ответы — те же файлы, что у AB3 (10
запросов корпуса из 10), колоды — те же 18 файлов, что растр Ш6: Ш8 наполнит кэш
тем, по чему выбирают. Команда с настоящим вызовом на VK Tech — 91 и 96 с на
три варианта. Тестовый текст для веба модель проваливает в обоих режимах —
опускает абзац с числами, — и сборка уходит путём без модели.

**Три набора.** Девятка: без модели 67 → 23, заслонено 19, картинок 11;
«оставить» 56 → 5, 9, 18; «доработать» 56 → 0, 9, 18. Растр просмотрен
глазами: заголовки-выводы и картинки — за колодами модели; сжатые подписи
VK Tech (`Z-55`) — у модели чаще (3, 12 и 21 слайд из 39); чужие числа донора на
