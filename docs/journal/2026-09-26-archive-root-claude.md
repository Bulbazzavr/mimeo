### Главное правило (26 сентября): сначала польза

Любую работу сначала оценить по пользе для сдачи и только потом делать. Лишних
проверок, прогонов и правок документов не делать. Смысл — текст, структура,
бриф, проверка слайдов — делает модель: ТЗ этого прямо требует. Подробно —
`mimeo/CLAUDE.md`, «Как здесь принято работать».

### Что это за проект

`mimeo` — движок переноса стиля презентаций: разбирает произвольный
`.pptx`-шаблон, извлекает дизайн-систему и библиотеку раскладок, раскладывает
контент и собирает готовый файл клонированием слайдов шаблона.

Задача Б4 хакатона ЛЦТ 2026, заказчик VK Tech. **Сдача 29 сентября 2026.**

### Первым делом

Шаблоны для проверки в репозиторий не коммитятся — они чужие:

```
cd mimeo
ls samples/*.pptx || python tools/fetch_samples.py samples
python -m pytest
```

**Материалы задачи лежат в `mimeo/tz/`** — выданные 15 сентября шаблоны, ТЗ и
памятка, плюс наши заметки о них (`tz/notes/README.md`). Каталог целиком
исключён из репозитория: данные ТЗ публиковать нельзя.
