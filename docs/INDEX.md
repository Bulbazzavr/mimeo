Планы со статусом «выполнено» продолжать не нужно. Тот, что «в работе», ведётся
по ходу: шаги отмечаются, находки дописываются в журнал выполнения. Новый план
заводится перед следующим крупным шагом; что это за шаг, говорит `BACKLOG`.

## Лабораторный журнал

[`WORKLOG/`](../WORKLOG/README.md) — сырые замеры и находки: числа, которые дорого
получить и легко потерять. Выводы из чисел живут в `docs/`, сами числа остаются
там.

## Инструменты и образцы

| Что | Зачем |
|---|---|
| `tools/fetch_samples.py` | Скачивает корпус реальных шаблонов в `samples/`. Они чужие и не коммитятся, но без них ничего не проверить на настоящих данных. |
| `tools/report.py` | Порождает таблицы замеров для `WORKLOG/`. Числа не пишутся руками. Стадия `quality` печатает весы колоды по корпусу и делит его на настроечную и отложенную части (`ADR-0019`). |
| `tools/build_verified.py` | Тонкая обёртка над `verify_deck`: то же, что `python -m mimeo build … --verify`, но с флагом `--rounds`. Петля живёт в продукте (`mimeo/verify/loop.py`). Запускает PowerPoint, нужно согласие пользователя. |
| `tools/rank_dump.py` | Показывает, какие раскладки пригодны каждому разделу и с каким рангом. Отвечает на вопрос «из чего был выбор», которого не видно в готовом плане (`PLAN-2.1`). |
| `tools/render_probe.py` | Открывает собранный файл в PowerPoint через COM и выгружает слайды в PNG. Заготовка рендерера VERIFY (`ADR-0013`); запускает настоящее приложение, поэтому только с согласия пользователя. Рядом `tools/com_probe.ps1` — сам зонд. |
| `examples/content-demo.md` | Наш демо-контент. Коммитится: нужен, чтобы всё воспроизводилось с нуля. |
| `THIRD-PARTY.md` | Сторонние компоненты и их лицензии. Требуется для open-source сдачи (`CTX-RULES`, п. 5.11); правило обновления — внутри. |

## Правила ведения

- Новый документ обязан появиться в этой таблице, иначе его никто не найдёт.
- ID не переименовываются. Файл можно передвинуть, ID остаётся.
- Документ, потерявший актуальность, не удаляется, а получает в шапке
  `status: obsolete` и ссылку на замену.
- **Документ не обещает несуществующего.** Если написано «пересоздать скриптом» —
  скрипт лежит в `tools/` и запускается. Это проверяется тестом
  `tests/test_docs.py`: он же следит, что ссылки ведут в существующие файлы,
  каждый документ найден с этой карты и каждое решение перечислено выше.
